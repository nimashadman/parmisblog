# مجلهٔ حسابداری پارمیس

افزونهٔ وردپرس برای بلاگ فارسی و راست‌به‌چپ پارمیس با قالب بنفش و یاسی.

## نصب

1. فایل `parmis-mag.zip` را از بخش افزونه‌ها در وردپرس بارگذاری و فعال کنید.
2. در «تنظیمات ← مجله پارمیس»، دسته‌ها و مقاله‌های منتخب را تعیین کنید.
3. شورت‌کد `[parmis_mag]` را در برگهٔ موردنظر قرار دهید.
4. برای حفظ هدر و فوتر قالب، از `[parmis_mag chrome="off"]` استفاده کنید.

جست‌وجوی فارسی، فیلتر موضوعی، مقاله‌های منتخب، مسیر مطالعه و چک‌لیست پایان ماه در افزونه موجود است. مقاله‌ها از نوشته‌های واقعی سایت خوانده می‌شوند. اطلاعات چک‌لیست فقط در مرورگر کاربر ذخیره می‌شود.

نیازمندی‌ها: وردپرس ۶.۲ به بالا و PHP ۷.۴ به بالا.

نسخهٔ فعلی: ۱.۰.۳. لوگوی ارسالی پارمیس در هدر و فوتر استفاده شده است. فوتر تمام‌عرض با فاصلهٔ کناری واکنش‌گرا نمایش داده می‌شود.

بررسی نحوی PHP انجام شده؛ بررسی نمای ظاهری و عملکرد روی وردپرس مقصد هنوز لازم است.

## ساختار

- `parmis-mag/`: کد افزونه و راهنمای نصب
- `parmis-mag.zip`: بستهٔ آمادهٔ نصب

برگرفته از CampShopping Magazine 1.0.3 تحت مجوز GPL-2.0-or-later. مجوز اصلی در پوشهٔ افزونه حفظ شده است. فونت وزیرمتن با مجوز SIL OFL همراه پروژه است.
